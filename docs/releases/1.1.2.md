# ManwhaTrack 1.1.2

## Changes

- Personal lists have a direct **Add series** picker with local search and cover previews. Save membership from the list page, or cancel without changing it. Manually tracked series are also assigned to the list currently open.
- Cover cards have contained borders, spacing and predictable widths. Personal lists no longer repeat the featured Continue banner. Compact, comfortable and large card sizes are available in settings.
- Expanded navigation groups the main views, personal lists and tools. Additional reading-status views live under **More views**.
- Large-screen outer margins have quiet, animated pixel scenery using the extension's existing local artwork. It stays outside the application, pauses on hidden pages, respects reduced motion and can be disabled.
- Scrollbars are hidden by default; wheel, trackpad and keyboard scrolling still work. Settings can restore scrollbar visuals.
- Settings use labeled Appearance, Library layout, Reading and New chapters sections with On/Off switches. New preferences control card size, expanded layout, background scenery, timer visibility and the featured Continue panel. Per-source checks and local site rules also use switches.
- Queues preference writes within a settings page so quick changes to multiple controls keep both values.
- Includes the 1.1.1 Nano Machine chapter repair, saved-position Resume in a separate browser window, and conservative active reading-time fixes.

## Install or update

Download `manwhatrack-1.1.2.zip` and extract it into a permanent folder. In `chrome://extensions`, enable Developer mode and choose **Load unpacked** with that folder.

For an existing installation, replace the build in the same folder and click **Reload** on the existing extension card. Refresh open reading tabs. Keep the existing installation to preserve its local library; removing the extension can erase its data. Settings → Import & export provides local backups.

The ZIP contains an unpacked Chrome extension. No account, server or additional permissions are required.
