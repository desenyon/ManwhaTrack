# ManwhaTrack 1.1.0

A local-only Chrome extension for tracking manhwa, manga and webtoon reading.

## Install or update

1. Download `manwhatrack-1.1.0.zip` from this release and extract it into a permanent folder.
2. Open `chrome://extensions`, enable Developer mode, choose **Load unpacked**, and select the extracted folder containing `manifest.json`.
3. Pin ManwhaTrack and click its bookmark icon to open the side panel. **Expand library** opens the full library in a tab.

For an existing unpacked installation, replace its files in the same folder and click **Reload** on its existing extension card. Export a backup from Settings → Import / export first. Removing and reinstalling the extension can remove its local data.

The ZIP is an unpacked extension build, not a Chrome Web Store installation. No account or server is required.

## Changes

- Violet engraving theme, simpler bookmark logo, clearer series rows, chapter/progress/source chips, and rebuilt expanded series details and list forms.
- Visibly moving hand/cloud layers and a bridge landscape with drifting clouds and water. The sidebar footer responds to both window height and library size. Play/Pause and General → Artwork motion provide explicit control, with System respecting reduced motion.
- A measured session timer beneath the library heading. It pauses when the chapter loses focus, the reader is outside the viewport, or activity stops for 90 seconds. The expanded Time tracking page shows locally recorded totals by series and chapter. Totals survive browser restarts; the live clock starts fresh.
- Exact Resume for scroll readers, persistent custom lists, searchable/filterable local tags, and bulk assignment.
- Storage, import, cover, tracking-lifecycle and privacy hardening, plus chapter-list extraction scoped to exclude recommendations on Madara and MangaThemesia pages.

## Limits

Detection and update checks depend on source-page markup. Paged/canvas readers resume the chapter rather than automatically selecting a page. Historical daily time cannot be reconstructed from older chapter totals. Existing chapter and history records are preserved rather than automatically rewritten.
