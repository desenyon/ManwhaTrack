# ManwhaTrack 1.2.2

Prepares the existing extension for a Chrome Web Store submission. Reading behavior, storage schema and permissions are unchanged.

- Updated public privacy policy with an explicit Chrome Web Store Limited Use statement, local data handling, direct source requests, retention/deletion and support contact. The extension ZIP includes the same policy.
- Added copy-ready listing text, permission justifications, data disclosures and reviewer instructions.
- Added five actual extension screenshots at 1280×800, a 440×280 promotional graphic and the existing 128×128 icon. Screenshot data uses an isolated fictional library and original procedural cover art.
- Added `npm run package:store` to validate and create a complete submission bundle.

Download `manwhatrack-1.2.2.zip` for the Chrome Developer Dashboard's package upload. Download and extract `manwhatrack-store-submission-1.2.2.zip` for the Store graphics, copy-ready fields and `UPLOAD.md` instructions. The outer bundle is not itself an extension package.

The developer must complete their publisher-account fields and submit the item through Google's review process. This release does not publish a Chrome Web Store listing.
