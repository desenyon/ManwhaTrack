# ManwhaTrack 1.1.1

## Changes

- Fixes Nano Machine chapter numbers on Asura when adjacent subtitle numbers and dates are joined into the chapter label. The local database upgrade repairs confidently identifiable automatic records, their update summaries and matching history labels. IDs, completion, progress, saved positions, reading time and explicit chapter corrections are preserved.
- Resume opens a separate browser window and restores the saved reading position. Modifier and middle-click continue to open a new tab.
- The expanded library defaults to larger cover cards and remembers its layout separately from the sidebar. Cards have readable progress chips and text Resume buttons. The Continue artwork, series details, metadata controls and chapter timeline have clearer spacing.
- Reading time pauses when meaningful reader content is missing or disconnected, in addition to focus, visibility, viewport and inactivity checks.

## Install or update

Download `manwhatrack-1.1.1.zip` and extract it into a permanent folder. In `chrome://extensions`, enable Developer mode and choose **Load unpacked** with that folder.

For an existing installation, replace the build in the same folder and click **Reload** on the existing extension card. Refresh open reading tabs. Keep the existing installation to preserve its local library; removing the extension can erase its data. Settings → Import / export provides local backups.

The ZIP contains an unpacked Chrome extension. No account, server or additional permissions are required.
