# ManwhaTrack 1.2.0

- Faster background clouds with the same dimness, reduced-motion behavior and pause controls.
- A simpler sidebar heading with a compact timer beside **Your Library**. Reading facts and source labels use less framing; format badges distinguish novels and manhwa.
- Expanded series details prioritize reading actions and the chapter timeline, with organization controls in a secondary column.
- Web novel detection recognizes substantial prose readers and Royal Road/Webnovel URL templates. Visible chapter labels take priority over opaque database IDs. Format and genre corrections remain user-owned. Novels use the existing local progress, saved-position Resume, covers, lists and backup system.
- **Analytics** adds weekly measurements, keyboard-accessible activity heatmaps, reading-time and backlog graphs, time of day, reading pace, series drill-downs, retention, genre/source breakdowns, neglected titles, reading fingerprints and dated milestones.
- Database schema 6 and backup format 5 preserve older libraries and totals. Dated measurements start with this version; undated historical time is never assigned invented dates or sessions. Backlog estimates are rough, and release timing means first observed updates rather than publisher release dates.
- Backup merges adopt growing minute measurements without counting the same activity twice.

## Install or update

Extract `manwhatrack-1.2.0.zip` into a permanent folder. Enable Developer mode in `chrome://extensions` and choose **Load unpacked** with that folder.

For an existing installation, replace the files in the same folder and click **Reload** on the existing extension card, then refresh reading tabs. Keep the existing extension installation to preserve its local library. Export a backup from Settings → Import & export before updating if desired.

No new permissions, accounts, external services or runtime dependencies. Novel template fixtures and local browser flows are tested; protected or unusual readers may need local rules or manual correction.
