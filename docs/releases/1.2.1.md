# ManwhaTrack 1.2.1

- Corrects Novel/Manhwa detection: translation notes around comic pages no longer replace the image reader, explicit format metadata outranks shared site routes, and ambiguous landing pages preserve an established label. Tapas episodes distinguish prose from image readers. Comic-only platform adapters preserve their format.
- Revisiting a reading page repairs an older automatically detected label without creating another series. Manual format choices remain authoritative in **Series details → Format**.
- Removes the footer subtitle and extra separator. Centers the collection caption, retains the motion control, and keeps format labels readable on compact covers.
- Analytics refreshes during continuous reading, ignores stale asynchronous responses, and reports failed refreshes with a Retry action. Short reading measurements show seconds. Calendar month labels and explicit analysis-period labels make the charts easier to inspect.
- Fixes ALL history when only backlog or update observations exist, sessions crossing week boundaries, zero-duration boundary sessions, and update deduplication across sources. Floating-point rounding no longer labels fresh measurements as undated historical time.

## Install or update

Extract `manwhatrack-1.2.1.zip` into a permanent folder and use **Load unpacked** in `chrome://extensions` with Developer mode enabled.

For an existing installation, replace the files in the same folder and click **Reload** on the existing extension card, then refresh reading tabs. Keep the existing installation to preserve the local library. Older automatic format mistakes correct when the series is revisited; a manual correction can be made immediately in its details.

No new permissions, storage schemas, accounts or external services. Daily reading time and sessions started recording in v1.2.0; earlier undated totals remain preserved but cannot populate historical daily charts.
