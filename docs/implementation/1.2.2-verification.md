# Chrome Web Store submission preparation — 1.2.2

This release changes packaging, policy and submission materials. There are no changes to reading behavior, permissions, dependencies, storage schema or backup format.

## Prepared

- Public `PRIVACY.md` includes a Limited Use compliance statement, local processing/storage, direct source requests, data retention/deletion, backup sharing and support contact. The build copies the same file into the extension ZIP.
- `chrome-web-store/listing.json` contains the listing, single purpose, every requested/optional permission justification, remote-code declaration and local data disclosures.
- The submission bundle provides plain-text `dashboard-fields.txt`, reviewer instructions, the privacy policy, upload instructions and the separately uploaded graphics.
- Five screenshots are actual production extension views at 1280×800. They use disposable fictional reading sites and procedural cover art. Synthetic dated history is used only for the Analytics demonstration.
- The 440×280 promotional image uses the existing purple-hands theme. The 128×128 icon matches the installed extension.

## Verified

- `npm run check`: TypeScript, 308 unit tests in 45 files and production build passed.
- Final TypeScript check passed after the capture script edits.
- Store asset capture passed with no page errors; verified automatic detection of four comics and a novel, list creation/membership, details, Analytics and settings in a separate browser profile. Screenshots were visually inspected.
- `npm run package:store` validates image dimensions, manifest/listing agreement, permission coverage, Limited Use text and source/package privacy equality. Both archives pass ZIP integrity checks.
