# Classification, footer and analytics verification — 1.2.1

## Reproduced failures and fixes

- A page-wide article containing long translation notes won reader selection over a nested comic image reader. Detection now keeps the dedicated reader; illustrated prose chapters remain novels.
- A generic landing page without format evidence defaulted its observation to Manhwa, overwriting a saved Novel label. Ambiguous observations now leave the saved format alone. Explicit metadata and dedicated comic platform adapters take priority over shared URL routes.
- Tapas episode URLs do not identify the reading format. Its focused prose/image content now supplies the format even when the generic detector cannot infer a parent series from the episode route.
- Continuous `library-changed` messages repeatedly reset the Analytics debounce. A bounded refresh interval now updates while reading continues. Request generation prevents an older asynchronous result from replacing newer records; refresh failures retain the last view and expose Retry.
- ALL excluded backlog-only history and earlier observed updates. Update deduplication happened after range filtering and could discard completion/opening data from another source. Sessions ending exactly at a period boundary were counted; sessions crossing into the current week were missed. Regression tests cover each case.
- Tiny differences between lifetime and dated time produced a historical-time notice on fresh activity. Calculation rounds to milliseconds; notices omit sub-second differences while lifetime totals remain intact.

## UI pass

Removed the requested footer subtitle and separator, centered the caption independently of the motion control, and retained adaptive bridge height and motion preferences. Compact cover labels no longer clip. Analytics adds month labels, clearly labeled periods, precise short-duration readings, and an explicit all-time chapter average.

Reviewed actual extension screenshots in light and dark themes: 280–380px panels, 320–2560px details and Analytics, expanded cards, chapter lists, list management and membership dialogs, and settings. Browser assertions check horizontal overflow, control bounds, centered footer text, responsive artwork, keyboard focus and reduced motion.
